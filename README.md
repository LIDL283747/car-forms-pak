# Справочник форм автомобилей

Учебный проект по веб-программированию: сайт-справочник типов кузова
автомобилей с административной панелью. Реализован на чистом HTML, CSS
и JavaScript — без сервера, фреймворков и базы данных.

## 🔗 Демо

**Публичная ссылка:** https://ВАШ-ЛОГИН.github.io/car-forms/

## Возможности

- Каталог форм кузова с поиском и фильтром по категории
- Постраничный вывод (6 карточек на страницу)
- Страница просмотра с галереей и счётчиком просмотров
- Административная панель с авторизацией
- Добавление, редактирование и удаление записей
- Загрузка изображений (JPG, PNG, WEBP, до 500 КБ)
- Управление категориями с защитой от удаления непустых
- Адаптивная вёрстка

## 🔐 Вход в админ-панель

## 🛠 Технологии

- HTML5
- CSS3 (Grid, Flexbox, CSS-переменные, `aspect-ratio`, `backdrop-filter`)
- JavaScript (ES2017+, async/await)
- LocalStorage и SessionStorage как хранилище
- FileReader API для загрузки изображений
- Web Crypto API для хеширования пароля (SHA-256)
